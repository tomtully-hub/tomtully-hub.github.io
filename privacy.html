Privacy and data use

Tom Research Index is a private tool operated by its owner for the owner's research library.

Google account access

The application requests permission to read Drive metadata, manage files created or explicitly used with the application, and run scheduled checks. Metadata includes file IDs, names, types, parent folders, sizes, timestamps, checksums, revision identifiers, shortcuts and Drive links. It does not request account-wide permission to download document contents.

Purpose and storage

Metadata supports inventory, identity matching, and detection of file additions, edits, moves, renames and removals. The script writes inventory output into its own folder in the owner's Google Drive. The owner's Mac receives the output through Google Drive sync and stores a local metadata ledger and verification receipts. Owner-controlled backups may retain copies.

Access and sharing

The data is available to the owner and authorized assistants maintaining the research system. Google provides Apps Script and Drive processing and storage. This application does not sell metadata, use it for advertising, or provide it to public users. This informational website contains no analytics or tracking code; the hosting provider may maintain standard access logs.

Retention and control

Inventory and verification records are retained until the owner removes them, including applicable backup copies. The owner can stop scheduled triggers and revoke the application's access through Google Account connections. Revocation stops future access but does not automatically erase existing inventory or backup records.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

For questions, use the owner support contact shown on the Google consent screen.
